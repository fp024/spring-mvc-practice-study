# DB 자동 증가 ID 초기화



## Oracle FREE 23c

`GENERATED BY DEFAULT AS IDENTITY` 로 자동증가 ID 컬럼을 정의 했을 때...  테스트 과정에서 증가된



#### 테이블 정의

```sql

CREATE TABLE TBL_BOARD (
    BNO         NUMBER(19)                   GENERATED BY DEFAULT AS IDENTITY,
    TITLE       VARCHAR2(500)                NOT NULL,
    CONTENT     VARCHAR2(2000)               NOT NULL,
    WRITER      VARCHAR2(50)                 NOT NULL,
    REGDATE     TIMESTAMP       DEFAULT SYSTIMESTAMP,
    UPDATEDATE  TIMESTAMP       DEFAULT SYSTIMESTAMP,
    DELFLAG     BOOLEAN         DEFAULT FALSE,
    CONSTRAINT PK_TBL_BOARD PRIMARY KEY (BNO)
);
```

#### SQL Mapper

`useGeneratedKeys="true"`로 자동생성된 키를 사용하겠다고 설정준 상태..

```xml
  <insert id="insert" 
          useGeneratedKeys="true" keyProperty="bno" keyColumn="BNO">
    INSERT INTO TBL_BOARD (title, writer, content)
    VALUES (#{title}, #{writer}, #{content})
  </insert>
```



#### 자동증가값 초기화 쿼리

다시 1로 초기화하고 싶을 때는... 테이블 비우고, 다시 1로 시작하게 바꿔준다.

```sql
-- 💡자동증가값을 1로 초기화할 때는 기존 내용을 버리겠다는 의도도 생겨셔,
--    테이블을 비워준다. 
-- TRUNCATE TABLE TBL_BOARD;  

ALTER TABLE TBL_BOARD
MODIFY BNO GENERATED BY DEFAULT AS IDENTITY
(RESTART START WITH 1);
```
