# HTML 공백 처리와 `&nbsp;` 사용 가이드

HTML 텍스트 작성 시 줄바꿈(엔터)이 화면에 렌더링되는 원리와 `&nbsp;` 엔티티의 적절한 사용 시점을 정리합니다.

---

## 1. HTML 공백 축약 (Whitespace Collapse) 규칙

HTML 표준(CSS `white-space: normal` 기본값)에서는 태그 내부의 **연속된 공백, 탭, 줄바꿈(엔터)**을 화면에 렌더링할 때 **단 하나의 공백 한 칸(` `)**으로 합쳐서(collapse) 처리합니다.

### 코드 예시
```html
<p>
  The time on the server is
  <span th:text="${serverTime}">2026-09-07 22:15:20</span>.
</p>
```

- `is` 뒤에 엔터(줄바꿈)와 다음 줄의 들여쓰기 공백들이 존재하더라도, 브라우저는 이를 모두 합쳐 **공백 1칸**으로 변환합니다.
- **실제 브라우저 화면 출력**:
  > `The time on the server is 2026-09-07 22:15:20.`

따라서 일반적인 문장에서 단어 사이를 1칸 띄우기 위해 굳이 `&nbsp;`를 넣을 필요가 없습니다.

---

## 2. `&nbsp;` (Non-Breaking Space)는 언제 써야 할까?

`&nbsp;`는 "줄바꿈이 되지 않는 공백(Non-Breaking Space)"이라는 특수 문자 엔티티입니다. 다음과 같은 상황에서 주로 사용합니다.

### 2.1. 2칸 이상의 연속 공백이 필요할 때
일반 스페이스는 아무리 여러 번 입력해도 1칸으로 합쳐지지만, `&nbsp;`는 개수만큼 그대로 여백이 유지됩니다.

```html
<!-- 일반 공백은 1칸으로 출력됨 -->
<p>Hello     World</p> <!-- 출력: Hello World -->

<!-- 여러 칸을 강제로 띄울 때 -->
<p>Hello&nbsp;&nbsp;&nbsp;World</p>
```

### 2.2. 특정 단어 사이의 줄바꿈을 방지하고 싶을 때
브라우저 창 크기가 줄어들더라도 숫자와 단위, 혹은 한 단어로 읽혀야 하는 텍스트가 줄 끝에서 분리되는 것을 방지합니다.

```html
<!-- 화면 폭이 좁아져도 '100'과 'km/h'가 분리되지 않고 함께 줄바꿈됨 -->
<span>시속 100&nbsp;km/h로 주행</span>
```

---

## 3. 요약 및 권장사항

| 상황 | 권장 방식 | 비고 |
| :--- | :--- | :--- |
| **일반적인 1칸 띄어쓰기** | 일반 공백(` `) 또는 줄바꿈(엔터) | `&nbsp;` 불필요, 가독성 유지 |
| **연속된 여러 칸 공백** | `&nbsp;` 반복 또는 CSS 마진(`margin`) | 디자인 레이아웃 목적이라면 CSS 권장 |
| **단어 줄바꿈 방지** | `&nbsp;` 또는 CSS `white-space: nowrap` | 텍스트의 결합성 유지 목적 |
